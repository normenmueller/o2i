Usage: o2i (--build-revision | COMMAND) [--version]

  Inspect an O2I model in one exact Archi View.

Available options:
  --build-revision         Write the bound source commit SHA.
  -h,--help                Show this help text
  --version                Show the O2I version.

Available commands:
  inspect                  Inspect one View of a native Archi model.
