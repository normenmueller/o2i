# O2I verstehen und anwenden

O2I beschreibt, wie aus Orientierung nachvollziehbare Wirkung entstehen soll.
Diese Dokumentation führt von den Begriffen zum eigenen Modell.

| Einstieg | Inhalt |
| --- | --- |
| [WTF](misc/wtf.md) | Begriffe kurz erklärt |
| [Modellierungs-Guide](guide/README.md) | Ein fiktives Beispiel mit angeleiteten Archi-Schritten und passenden Views aufbauen und prüfen |
| [Beispielmodell](model/illustration.archimate) | Das gemeinsame, schrittweise wachsende Modell für Guide und Prüfungen |
| [White Paper](paper/o2i.md) · [PDF](paper/o2i.pdf) | Fachliche Definitionen, Metamodell und konkrete Syntax |

Beginne mit den Begriffen oder direkt mit [„Einen Ethos modellieren“](guide/ethos.md).
Das White Paper vertieft die Regeln hinter den einzelnen Schritten.

[Installation und CLI](../spec/README.md#cli-setup) sowie
[Beiträge und Dokumentationsbau](../CONTRIBUTING.md) beschreiben die technische Arbeit.
Abbildungen liegen unter [images/](images/), ihre Quellen und Render-Zubehör unter [resources/](resources/).
